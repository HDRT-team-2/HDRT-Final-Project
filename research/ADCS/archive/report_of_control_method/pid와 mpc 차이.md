# PID 제어기와 MPC 제어기의 비교 및 전차 제어 적용성 분석 보고서

---

## 1. 보고 목적

본 문서는 **PID 제어기 (Proportional–Integral–Derivative Controller)** 와  
**모델 예측 제어기 (Model Predictive Control, MPC)** 의 제어 원리 및 성능 차이를 분석하고,  
이를 실제 **전장 환경에서 운용되는 전차의 실시간 제어기 설계 관점**에서 비교·평가하기 위함이다.

---

## 2. 제어 개념 비교

| 구분 | PID 제어 (Proportional-Integral-Derivative) | MPC 제어 (Model Predictive Control) |
|------|---------------------------------------------|-------------------------------------|
| **기본 원리** | 현재 오차(`에러값 = 현재값 - 보정값`)를 기반으로 즉시 보정. 과거 누적 오차 및 오차 변화율을 이용하여 제어 입력 계산. | 시스템의 수학적 모델을 기반으로 미래 상태를 예측하고, 일정 예측 구간(horizon) 동안의 비용함수(cost function)를 최소화하도록 제어 입력 최적화. |
| **핵심 구성 요소** | - P(비례): 현재 오차 크기<br>- I(적분): 누적 오차<br>- D(미분): 오차 변화율 | - 시스템 모델(상태방정식)<br>- 비용함수(목표 및 제약 조건)<br>- 최적화 알고리즘(QP, NLP 등) |
| **수학적 형태** | `u(t) = Kp * e(t) + Ki * ∫e(t)dt + Kd * de(t)/dt` | `min(u0...N) Σ (||x_k - x_ref||_Q^2 + ||u_k||_R^2)`<br>subject to: `x_(k+1) = A x_k + B u_k` |
| **시간 기반 계산 구조** | 실시간 폐루프(Feedback) 기반의 반복 계산 | 예측 창(horizon) 내의 최적화 문제를 매 시간 간격마다 재계산 |
| **모델 필요 여부** | 필요 없음 (경험적 제어 가능) | 필수 (정확한 시스템 모델 필요) |
| **예측 기능** | 없음 (반응형 제어) | 있음 (예측 기반 제어) |
| **계산 복잡도** | 매우 낮음 (수 µs ~ 수 ms 단위) | 매우 높음 (수십~수백 ms 이상) |
| **강건성 (Robustness)** | 모델 오차, 외란, 마찰 변화 등에 강함 | 모델 불일치나 외란에 취약 |
| **적용 예시** | 차량 스티어링, 엔진 속도 제어, 서보 모터 제어 | 자율주행 경로 추종, 로켓 궤적 최적화, 고속차량 차간거리 제어 |

---

## 3. 동작 메커니즘 비교

### (1) PID 제어의 폐루프 구조

PID 제어기는 **오차의 실시간 갱신 및 보정 루프 (feedback loop)** 를 통해 목표 상태에 점진적으로 수렴한다.


즉, MPC는 **예측 + 최적화 + 제약조건 처리**를 통해 정밀 제어를 수행하지만,  
매 루프마다 최적화 문제를 풀어야 하므로 **고연산 자원**과 **모델 정확도**가 필요하다.

---

## 4. 전장 환경에서의 제어기 요구 조건

| 항목 | 전차 제어 환경의 특성 |
|------|------------------------|
| **실시간성** | 즉각적인 조향 응답 필요 (수 Hz~수백 Hz 제어 주기) |
| **강건성** | 진동, 피탄, 지면 마찰 변화 등 외란 다수 |
| **신뢰성** | 센서 손상, 전원 불안정 상황에서도 기본 제어 유지 필요 |
| **모델 불확실성** | 마찰계수, 경사각, 하중 중심 변화 등 예측 불가 |
| **연산 한계** | 내장형 제어보드, 제한된 CPU 자원 |

이런 조건에서는 **단순·신속·안정적인 폐루프 제어기**가 필수적이다.

---

## 5. PID vs MPC의 전장 적용성 평가

| 평가 항목 | PID 제어 | MPC 제어 |
|------------|-----------|-----------|
| 실시간 응답성 | 매우 빠름 (µs~ms 단위) | 상대적으로 느림 (ms~s 단위) |
| 연산 자원 요구 | 저연산 | 고연산 (QP/NLP 필요) |
| 모델 의존성 | 비모델 기반 (경험 제어 가능) | 모델 정확도 필수 |
| 외란 대응성 | 강건 | 모델 오차에 취약 |
| 제약조건 처리 | 불가능 (단순 한계값 제한만 가능) | 명시적 제약조건 처리 가능 |
| 제어 안정성 | 고신뢰, 단순 튜닝 | 조건부 안정성 |
| 실전 적용성 (전차 등) | 매우 적합 | 비현실적 (연산 지연 위험) |

---

## 6. 결론 및 제언

1. **전차와 같은 군용 지상 플랫폼**은  
   - 비정형 지형, 외란, 충격 등 불확실 요소가 많고  
   - 실시간 응답성과 강건성이 절대적으로 요구된다.

2. **MPC는 이론적으로 최적이지만**,  
   - 연산량이 과도하고  
   - 모델 불확실성이 큰 환경에서는 **신뢰도 저하**를 초래한다.

3. 따라서 전차 제어 시스템의 구조적 설계는 다음과 같이 계층화하는 것이 이상적이다.
